# 调用约定  

调用约定描述了如何在函数之间传递变量。如果仅使用自己构建的函数,则不必关心调用约定。    

Linux使用SystemV AMD64 ABI调用约定，Windows使用Microsoft x64调用约定。    

## SystemV amd64 函数参数传递    

### 非浮点参数（整数和地址）：  

第一个：放入rdi    
第二个：放入rsi  
第三个：放入rdx  
第四个：放入rcx  
第五个：放入r8  
第六个：放入r9  
其他：
压入第十个参数  
压入第九个参数  
压入第八个参数  
压入第七个参数  

> Linux SystemV ABI要求栈帧16字节对齐，call指令执行前，rsp必须是16的倍数。    

> 每压入一个参数，sp减少8字节。调用函数时rip压入也会8个字节，函数序言压入rbp也会导致sp减少8个字节。    

> 因此，要在函数中访问参数，必须跳过栈上前16个字节，如果必须对齐栈，则可能跳过更多字节。    


### 浮点参数：  

第一个：放入xmm0  
第二个：放入xmm1  
第三个：放入xmm2  
第四个：放入xmm3  
第五个：放入xmm4  
第六个：放入xmm5  
第七个：放入xmm6  
第八个：放入xmm7  
其他参数通过栈传递。    


## 保留寄存器  

在执行函数期间，某些寄存器的值将会被更改，而某些寄存器的值保持不变。你需要采取预防措施，以避免因函数修改你在主调函数中使用的寄存器而导致意外。    


|寄存器|用例|保存|
|-|-|-|
|rax|返回值|Caller|  
|rbx|被调用者保存|Callee|
|rcx|第四个参数|Caller|
|rdx|第三个参数|Caller|
|rsi|第二个参数|Caller|
|rdi|第一个参数|Caller|
|rbp|被调用者保存|Callee|
|rsp|栈指针|Callee|
|r8|第五个参数|Caller|
|r9|第六个参数|Caller|
|r10|临时寄存器|Caller|
|r11|临时寄存器|Caller|
|r12|被调用者保存|Callee|
|r13|被调用者保存|Callee|
|r14|被调用者保存|Callee|
|r15|被调用者保存|Callee|
|xmm0|第一个浮点参数/返回值|Caller|
|xmm1|第二个浮点参数|Caller|
|xmm2-xmm7|浮点参数|Caller|
|xmm8-xmm15|临时寄存器|Caller|

### 简单分类

Caller保存寄存器（易失性）

- **通用寄存器**: rax, rcx, rdx, rsi, rdi, r8, r9, r10, r11  
- **浮点寄存器**:   xmm0-xmm15    
- **特点**: 函数可以随意修改，调用者如需保护必须自己保存。  

Callee保存寄存器（非易失性）

- **通用寄存器**: rbx, rbp, rsp, r12, r13, r14, r15
- **特点**: 函数如要使用必须先保存并在返回前恢复。  

> CRE:助记：传参和返回用的寄存器通常是Caller保存，其余由Callee保存。  

> CRE:助记：Caller保存意味着“所有权”在Callee，Callee保存意味着“所有权”在Caller，借用请还原。      

> CRE:两个例外：临时寄存器r10, r11，虽然不是参数寄存器，但也是Caller保存，临时寄存器xmm8-xmm15，也是Caller保存    

> CRE:Caller保存寄存器：如果Caller需要在函数调用后继续使用这些寄存器的值，必须在调用前保存它们。  

> CRE:Callee保存寄存器：如果Callee要使用这些寄存器，Callee需要负责保存和复原寄存器的原值。

# Window x64 调用约定  

## 参数传递  

在Windows x64调用约定中，参数传递遵循以下规则：  
- 前四个整数或指针参数通过寄存器传递：  
  - 第一个参数(非浮点数/浮点数)：`rcx`/`xmm0`  
  - 第二个参数(非浮点数/浮点数)：`rdx`/`xmm1`    
  - 第三个参数(非浮点数/浮点数)：`r8`/`xmm2`    
  - 第四个参数(非浮点数/浮点数)：`r9`/`xmm3`  
- 如果有更多参数，则通过栈传递，栈指针`rsp`向下移动。  



- 调用者需要在堆栈上提供一个32字节的影子空间，以便将4个函数参数传递给被调用者，即使被调用者没有接受那么多参数。    

- 也像SystemV一样要求栈帧16字节对齐，但是不严格，有时不对齐也能工作，但是建议对齐。    


## 使用四个以上参数    

```asm
push rbp  
mov rbp, rsp
    sub rsp 8  ;调用之前16字节对齐  
    mov rcx, fmt
    mov rdx, arg1
    mov r8, arg2
    mov r9, arg3
    push arg10  ;其余参数反向压入  
    push arg9
    push arg8
    push arg7
    push arg6
    push arg5
    push arg4
    sub rsp, 32 ;影子空间  
    call printf
    add rsp, 32+8  ;恢复栈  
leave
ret
``` 


## 可变参数函数    

在Windows中，如果前四个参数有xmm寄存器，则必须将它们复制到相应的整数参数寄存器中。   

> CRE:实测实际生效的是整数寄存器中存储的浮点数值，而不是xmm中的浮点数值。  

```asm
;......
mov rcx, fmt
movq xmm0, [one]
movq rdx, xmm0

movq xmm1, [two]
movq r8, xmm1

movq xmm2, [three]
movq r9, xmm2
call printf
;......

```
