# x64栈帧    

## 栈对齐    

x64要求栈帧必须是16字节对齐。为什么不是8字节(64位)，因为有一些SIMD指令对较大的数据块执行并行操作，并且这些SIMD指令可能要求这些数据位于内存中16字节倍数的地址上。    

### 函数调用时的自动对齐  

x64 ABI要求在函数调用时，栈指针(RSP)必须是16字节对齐的。这是因为：  
1. call 指令会将返回地址（8字节）压入栈。  
2. 调用前RSP必须是16字节对齐，调用后就变成了8字节对齐。  


### 函数序言中的对齐处理  

```asm
; 典型的函数序言
push rbp        ; 保存旧的基指针 (8字节)
mov rbp, rsp    ; 设置新的栈帧基指针
; 此时RSP又回到16字节对齐状态

; 如果需要分配局部变量空间，确保分配的大小是16的倍数
sub rsp, 32     ; 分配32字节（16字节对齐）
```


### 手动对齐栈指针  

当需要动态对齐时：  

```asm
; 保存原始栈指针
mov rbp, rsp

; 对齐到16字节边界
and rsp, -16    ; 清除低4位，强制16字节对齐

; 或者使用减法方式
sub rsp, 15
and rsp, -16
```


## 补充    

### 叶子函数  

叶子函数是指不调用其他函数的函数。它们可以省略栈帧的建立和销毁，直接返回。对于叶子函数，编译器可以优化调用过程，减少栈操作，提高性能。如果不使用SIMD则不必担心对齐问题。        

但是有栈帧更便于调试器追踪。
