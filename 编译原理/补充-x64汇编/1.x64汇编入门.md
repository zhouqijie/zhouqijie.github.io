# Hello World  

## 汇编程序结构    

- 三个主要组成部分    
    + .data段  
    + .bss段  
    + .text段  

### .data段    

在 data section 中,使用以下格式声明和定义初始化数据：  
`<变量名> <类型> <值>`  

如果数据段中包含变量，当源代码被汇编并链接到可执行文件时，将为该变量分配内存。变量名称是符号名称，对内存位置和变量的引用可以占用一个或多个内存位置。变量名称是指变量在内存中的起始地址。    

.data段还可以包含常量，常量是程序中无法更改的值，声明格式：  
`<常量名称> equ <值>`  


| 指令 | 含义 | 大小 | 示例 |
|------|------|------|------|
| `db` | Define Byte | 1字节 | `var1 db 10` |
| `dw` | Define Word | 2字节 | `var2 dw 1000` |
| `dd` | Define Doubleword | 4字节 | `var3 dd 100000` |
| `dq` | Define Quadword | 8字节 | `var4 dq 1000000000` |
| `dt` | Define Ten bytes | 10字节 | `var5 dt 3.14159` |


```C++
// 这些会存放在 .data 段
int global_var = 42;                    // 初始化的全局变量
static int static_var = 100;           // 初始化的静态变量
const char* message = "Hello World";   // 初始化的指针
double pi = 3.14159;                   // 初始化的浮点数
int array[5] = {1, 2, 3, 4, 5};       // 初始化的数组

// 类的静态成员变量（如果有初始值）
class MyClass {
public:
    static int count = 0;  // 初始化的静态成员（C++11后）
};
```

### .bss段  

bss表示*以符号开头的块(block started by symbol)*，用来存放未初始化的变量、    

bss段中的变量不包含任何值，这些值将在稍后的执行中分配。内存位置不是在编译时保留的，而是在执行时保留的。    

bss变量在程序开始执行时，从操作系统请求内存并初始化为零。    


| 指令 | 含义 | 单位大小 | 示例 |
|------|------|----------|------|
| `resb` | Reserve Bytes | 1字节 | `buffer1 resb 100` |
| `resw` | Reserve Words | 2字节 | `buffer2 resw 50` |
| `resd` | Reserve Doublewords | 4字节 | `buffer3 resd 25` |
| `resq` | Reserve Quadwords | 8字节 | `buffer4 resq 12` |
| `rest` | Reserve Ten bytes | 10字节 | `buffer5 rest 5` |

```C++
// 这些会存放在 .bss 段
int global_uninitialized;              // 未初始化的全局变量
static int static_uninitialized;       // 未初始化的静态变量
int zero_array[1000];                  // 未初始化的大数组
static char buffer[4096];              // 未初始化的静态数组

// 显式初始化为0的变量也可能放在 .bss
int global_zero = 0;                   // 编译器优化可能放入 .bss
static double static_zero = 0.0;       // 同上
// 类的静态成员变量（如果未初始化）
class MyClass {
public:
    static int uninitialized_count;    // 未初始化的静态成员
};
```



### .txt段    

代码段，存放可执行代码。    

> 代码段有时候也用.code表示。  

## 代码示例1(linux的系统调用打印HelloWorld)  

```asm
;Hello.asm
section .data
    msg db "Hello World", 0
section .bss
section .text
    global main
main:
    mov  rax, 1     ;1表示写入
    mov  rdi, 1     ;1表示标准输出
    mov  rsi, msg   ;需要显示的是字符串存放在rsi中  
    mov  rdx, 12    ;字符串长度，不包括0  
    syscall         ;显示字符串  
    mov  rax, 60    ;60表示退出  
    mov  rdi, 0     ;0是成功退出代码
    syscall         ;退出  
```

> `main:`部分称为标签。   
> `mov`称为复制指令，它将从源复制到目标。   
> 系统调用(`syscall`)适用于Linux，Windows不开放系统调用。    

## 代码示例2(win64调用printf打印HelloWorld)  

```asm
section .data
    msg db "HelloWorld", 0
    fmtstr db "This is string: %s", 10, 0

section .text
    global main
    extern printf

main:
    sub rsp, 40                ; 栈16字节对齐，预留shadow space
    lea rcx, [rel fmtstr]      ; 第1参数: 格式字符串
    lea rdx, [rel msg]         ; 第2参数: 字符串
    call printf
    add rsp, 40
    ret
```

> windows系统使用rcx、rdx、r8、r9传递前四个整型参数。  
> 汇编中不需要以0结尾的字符串，但是printf需要以0结尾的字符串。

## 指令指针寄存器(rip)  

处理器通过将下一条指令的地址存储在rip寄存器中。    


## 标志寄存器(rflags)  

标志寄存器（rflags）用于存储CPU在运算过程中产生的各种状态标志位，例如零标志（ZF）、进位标志（CF）、溢出标志（OF）等。这些标志用于判断运算结果、控制条件跳转和影响指令执行流程。  

## xmm寄存器和ymm寄存器    

用于浮点数计算和SIMD。
