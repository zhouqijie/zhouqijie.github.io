## 跳转和循环  

### 无条件跳转指令  

无条件跳转指令`jmp`，无论标志和条件，程序都会调转到指定标签。  

### cmp和条件跳转指令    

示例：
```asm
cmp rax, rbx
jge xxx
```  

> cmp 指令是汇编语言中的一条常用指令，主要用于比较两个操作数的大小。它的本质是做减法，但不保存结果，只影响CPU的标志位。（详见[标志位相关指令](#标志位相关指令)）    

> jge 是 x64 汇编中的条件跳转指令，全称是 Jump if Greater or Equal，即“如果大于等于则跳转”。    


### 无条件跳转指令  

|指令|含义|说明|
|-|-|-|
|jmp|无条件跳转|无论标志和条件，程序都会跳转到指定标签|

### 条件跳转指令  

|指令|标志|含义|应用|
|-|-|-|-|
|je|ZF=1|相等跳转|有符号、无符号|
|jne|ZF=0|不相等跳转|有符号、无符号|
|-|-|-|-|
|jg|(SF XOR OF) OR ZF = 0|大于跳转|有符号|
|jge|(SF XOR OF) = 0|大于等于跳转|有符号|
|jl|(SF XOR OF) = 1|小于跳转|有符号|
|jle|(SF XOR OF) OR ZF = 1|小于等于跳转|有符号|
|-|-|-|-|
|ja|CF=0 AND ZF=0|无符号大于跳转|无符号|
|jae|CF=0|无符号大于等于跳转|无符号|
|jb|CF=1|无符号小于跳转|无符号|
|jbe|CF=1 OR ZF=1|无符号小于等于跳转|无符号|
|-|-|-|-|
|jz|ZF=1|零标志跳转|等同于je|
|jnz|ZF=0|非零标志跳转|等同于jne|
|jc|CF=1|进位标志跳转|检测进位|
|jnc|CF=0|无进位标志跳转|检测无进位|
|jo|OF=1|溢出标志跳转|检测溢出|
|jno|OF=0|无溢出标志跳转|检测无溢出|
|js|SF=1|符号标志跳转|检测负数|
|jns|SF=0|无符号标志跳转|检测正数|
|jp/jpe|PF=1|奇偶标志跳转|检测偶数个1位|
|jnp/jpo|PF=0|无奇偶标志跳转|检测奇数个1位|

> 在X64汇编中，je(Jump if Equal)和jz(Jump if Zero)指令在功能上是完全相同的。它们是同一条机器指令的两种不同助记符。je通常用在cmp指令之后，表示“如果两个操作数相等则跳转”。这使得代码意图更清晰。

## 内存和寄存器操作    

### 变量取值指令    

使用方括号取变量的值`[var1]`。    

> CRE:变量是地址，方括号相当于C语言的解指针操作。    

> GPT:不同于x86(32位)默认的绝对寻找，x64默认使用RIP相对寻址。NASM需要在变量名前显式加上`rel`。    

### mov指令    

使用`mov`指令将一个值从一个寄存器或内存位置复制到另一个寄存器或内存位置。    

### lea指令  

`lea`指令（Load Effective Address）用于计算地址，而不是加载数据。它通常用于计算内存地址或偏移量。  

> 有效的意思是指的是最终实际使用的地址。

## 整数运算    

### `add`/`sub`指令    

`add`指令用于将两个操作数相加，并将结果存储在第一个操作数中。    
`sub`指令用于将第二个操作数从第一个操作数中减去，并将结果存储在第一个操作数中。  

> CRE：或者说add是把第二个值添加到第一个值，sub是从第一个值中减去第二个值。    

```asm  
;示例
mov rax, [number1]
add rax, [number2]  ;将number2的值添加到rax中
```  

### `mul`/`div`/`imul`/`idiv`指令  

`mul`指令用于无符号整数的乘法运算。它可以处理一个或两个操作数，并将结果存储在寄存器中。
`div`指令用于无符号整数的除法运算。它将被除数存储在寄存器中，并将结果存储在商和余数寄存器中。
`imul`指令用于有符号整数的乘法运算。它可以处理一个或两个操作数，并将结果存储在寄存器中。  
`idiv`指令用于有符号整数的除法运算。它将被除数存储在寄存器中，并将结果存储在商和余数寄存器中。  

```asm
;示例  
mov rax, [number1]  
imul qword [number2]  ;将rax乘以number2的值。qword用于告知汇编器内存操作数的大小。     
```

> imul和idiv有单操作数、双操作数、三操作数形式。单操作数使用默认是寄存器rax，双操作数或三操作数可以使用其他寄存器。但是mul指令只有单操作数形式。    

|特性|MUL|IMUL|
|-|-|-|
|操作数个数|仅1个|1个、2个、3个|
|数据类型|无符号|有符号|
|结果存储|固定寄存器对|	灵活|
|立即数	|不支持|支持|



### `inc`/`dec`指令  

`inc`指令用于将操作数的值增加1。它通常用于循环计数或递增变量的值。    
`dec`指令用于将操作数的值减少1。它通常用于循环计数或递减变量的值。  

### `shl`/`shr`/`sal`/`sar`指令  

`shl`指令（Shift Logical Left）用于将操作数的位向左移动指定的位数，并在右侧填充0。它通常用于乘以2的幂。  
`shr`指令（Shift Logical Right）用于将操作数的位向右移动指定的位数，并在左侧填充0。它通常用于除以2的幂。  
`sal`指令（Shift Arithmetic Left）用于将操作数的位向左移动指定的位数，并在右侧填充0。它通常用于乘以2的幂。  
`sar`指令（Shift Arithmetic Right）用于将操作数的位向右移动指定的位数，并在左侧填充符号位。  


|指令	方向|	填充方式|	符号位|
|-|-|-|
|SAL	算数左移|	右边填0|	不保证保留|
|SAR	算数右移|	左边填符号位|	保留(称为符号扩展)|
|SHL	逻辑左移|	右边填0|	不考虑符号|
|SHR	逻辑右移|	左边填0|	不考虑符号|

> AI:实际上SAL和SHL是同一条指令，都是逻辑左移，不考虑符号位保护。只有SAR是真正的"算术"移位，专门设计来保持符号的正确性。

## 浮点运算指令      

> 单精度浮点数1位符号位、8位阶码、23位尾数。  
> 双精度浮点数1位符号位、11位阶码、52位尾数。  

`movsd`:将双精度浮点数从一个位置移动到另一个位置。（`mov`指令不能用于xmm寄存器）    
`addsd`:将两个双精度浮点数相加。  
`subsd`:将一个双精度浮点数从另一个双精度浮点数中减去。  
`mulsd`:将两个双精度浮点数相乘。  
`divsd`:将一个双精度浮点数除以另一个双精度浮点数。  
`sqrtsd`:计算双精度浮点数的平方根。  

> "sd"意思是scalar double，scalar表示单个数值而非向量，double表示双精度浮点数。  

> 第一个操作数只能是xmm寄存器。

## 位运算    

#### 1. AND - 按位与
- **功能**: 对两个操作数进行按位与运算
- **语法**: `AND dest, src`
- **标志位**: 影响ZF、SF、PF，清除CF和OF

```asm
; 示例：清除特定位
mov rax, 0xFF0F    ; rax = 1111111100001111b
and rax, 0x0F0F    ; rax = 0000111100001111b，清除高4位和次高4位
```

#### 2. OR - 按位或
- **功能**: 对两个操作数进行按位或运算
- **语法**: `OR dest, src`
- **标志位**: 影响ZF、SF、PF，清除CF和OF

```asm
; 示例：设置特定位
mov rax, 0x0F0F    ; rax = 0000111100001111b
or rax, 0xF0F0     ; rax = 1111111111111111b，设置其他位为1
```

#### 3. XOR - 按位异或
- **功能**: 对两个操作数进行按位异或运算
- **语法**: `XOR dest, src`
- **标志位**: 影响ZF、SF、PF，清除CF和OF

```asm
; 示例：翻转特定位或清零寄存器
xor rax, rax       ; 快速清零rax寄存器
mov rbx, 0xAAAA
xor rbx, 0xFFFF    ; 翻转所有位
```

#### 4. NOT - 按位取反
- **功能**: 对操作数进行按位取反
- **语法**: `NOT dest`
- **标志位**: 不影响任何标志位

```asm
; 示例：按位取反
mov rax, 0x0F0F    ; rax = 0000111100001111b
not rax            ; rax = 1111000011110000b
```

#### 1. SHL/SAL - 逻辑左移/算术左移
- **功能**: 向左移位，右侧补0
- **语法**: `SHL dest, count` 或 `SAL dest, count`

```asm
; 示例：左移相当于乘以2的幂
mov rax, 5         ; rax = 5
shl rax, 2         ; rax = 20 (5 * 4)
```

#### 2. SHR - 逻辑右移
- **功能**: 向右移位，左侧补0
- **语法**: `SHR dest, count`

```asm
; 示例：无符号数右移
mov rax, 20        ; rax = 20
shr rax, 2         ; rax = 5 (20 / 4)
```

#### 3. SAR - 算术右移
- **功能**: 向右移位，左侧补符号位
- **语法**: `SAR dest, count`

```asm
; 示例：有符号数右移
mov rax, -20       ; rax = 负数
sar rax, 2         ; 保持符号的除法
```

#### 4. ROL - 循环左移
- **功能**: 向左循环移位(从左端移出的位会重新进入右端)  
- **语法**: `ROL dest, count`

```asm
; 示例：循环左移
mov al, 10001001b  ; al = 137
rol al, 3          ; al = 01001100b
```

#### 5. ROR - 循环右移
- **功能**: 向右循环移位(从右端移出的位会重新进入左端)  
- **语法**: `ROR dest, count`

```asm
; 示例：循环右移
mov al, 10001001b  ; al = 137
ror al, 3          ; al = 00110001b
```

#### 6. RCL - 带进位循环左移
- **功能**: 包含进位标志的循环左移
- **语法**: `RCL dest, count`

#### 7. RCR - 带进位循环右移
- **功能**: 包含进位标志的循环右移
- **语法**: `RCR dest, count`

## 标志位相关指令      

#### RFLAGS寄存器的重要标志位    

Bit 0:  CF (Carry Flag)        - 进位标志
Bit 2:  PF (Parity Flag)       - 奇偶标志  
Bit 6:  ZF (Zero Flag)         - 零标志
Bit 7:  SF (Sign Flag)         - 符号标志
Bit 8:  TF (Trap Flag)         - 陷阱标志
Bit 9:  IF (Interrupt Flag)    - 中断标志
Bit 10: DF (Direction Flag)    - 方向标志
Bit 11: OF (Overflow Flag)     - 溢出标志


#### 清除和设置指令    

|指令|作用|标志位|
|-|-|-|
|cld|清除方向标志|DF=0（正向）|
|std|设置方向标志|DF=1（反向）|
|clc|清除进位标志|CF=0|
|stc|设置进位标志|CF=1|
|cmc|取反进位标志|CF=!CF|
|cli|清除中断标志|IF=0|禁用可屏蔽中断|
|sti|设置中断标志|IF=1|启用可屏蔽中断|


#### cmp指令    

功能：  
- CMP指令执行比较操作，它实际上是对目标操作数减去源操作数，但不保存结果，只根据运算结果设置标志位。    

影响的标志位：  
- ZF (零标志位): 如果两个操作数相等，ZF=1    
- CF (进位标志位): 如果destination < source (无符号比较)，CF=1    
- SF (符号标志位): 反映减法结果的符号    
- OF (溢出标志位): 检测有符号运算溢出    
- AF (辅助进位标志位): 用于BCD运算    
- PF (奇偶标志位): 反映结果低8位的奇偶性    

#### 位测试指令    

TEST - 测试位
- **功能**: 执行AND运算但不保存结果，只影响标志位
- **语法**: `TEST dest, src`

```asm
; 示例：测试特定位是否设置
mov rax, 0x0F
test rax, 0x01     ; 测试最低位
jnz bit_is_set     ; 如果位为1则跳转
```

BT - 位测试
- **功能**: 测试指定位并将其复制到CF
- **语法**: `BT dest, bit_offset`

BTS - 位测试并设置
- **功能**: 测试指定位，复制到CF，然后设置该位
- **语法**: `BTS dest, bit_offset`

BTR - 位测试并重置
- **功能**: 测试指定位，复制到CF，然后清除该位
- **语法**: `BTR dest, bit_offset`

BTC - 位测试并取反
- **功能**: 测试指定位，复制到CF，然后翻转该位
- **语法**: `BTC dest, bit_offset`

```asm
; 位测试指令示例
mov rax, 0xFF
bt rax, 3          ; 测试第3位，结果存入CF
bts rax, 0         ; 测试并设置第0位
btr rax, 7         ; 测试并清除第7位
btc rax, 4         ; 测试并翻转第4位
```

#### 扫描指令    


BSF - 正向位扫描
- **功能**: 从低位开始扫描第一个设置的位
- **语法**: `BSF dest, src`

BSR - 反向位扫描
- **功能**: 从高位开始扫描第一个设置的位
- **语法**: `BSR dest, src`

#### 常用位操作技巧    

快速清零
```asm
xor rax, rax       ; 比 mov rax, 0 更高效
```

检查奇偶性
```asm
test rax, 1        ; 检查最低位
jz even            ; 偶数跳转
```

提取特定位域
```asm
; 提取bits 4-7
mov rax, data
shr rax, 4         ; 右移4位
and rax, 0x0F      ; 保留低4位
```

设置/清除特定位
```asm
; 设置第n位
bts rax, n

; 清除第n位  
btr rax, n

; 或使用传统方法
or rax, (1 << n)   ; 设置第n位
and rax, ~(1 << n) ; 清除第n位
```

## 函数以及堆栈相关指令      

### `push`/`pop`指令    
堆栈从高位内存开始，向低地址增长。使用`push`指令将对象放在堆栈上，使用`pop`指令将对象从堆栈删除，每次执行`push`堆栈就会增加，每次执行`pop`，堆栈就会减小。    

> AI:pop指令每次分配8字节（64位），push指令每次释放8字节（64位）。  
> CRE:push指令可看作sub+mov指令的语法糖。    
 

```asm
function_name:  
    push rbp                ; 保存旧的基指针
    mov rbp, rsp            ; 设置新的基指针
    sub rsp, 32             ; 为局部变量分配空间

    ; 函数体代码

    mov rsp, rbp            ; 恢复栈指针
    pop rbp                 ; 恢复旧的基指针
    ret                     ; 返回到调用者   
```

也可以使用复合指令enter和leave建立和销毁栈帧。(enter性能很差)    

函数需要一个序言和一个尾声。    

函数可以拥有自己的.data和.bss段。    

函数不能嵌套。

函数可以调用其他函数。
