# 字符串    

在汇编语言中，任何连续内存位置的列表或数组都被认为是一个字符串。汇编并不关心字符是否可读。    

> CRE:汇编中的字符串含义更接近“字节串”或者“字节数组”。    

## 处理字符串的相关指令  


`movsb` (Move String Byte)  
作用：将一个字节从源地址rsi复制到rdi目标地址。  
执行后自动更新rsi和rdi指针。  
方向由方向标志(DF)决定，DF为0递增，为1递减。  

`cmpsb` (Compare String Byte)  
作用：比较源地址(RSI)和目标地址(RDI)的一个字节。  
设置标志位但不修改内存。  
执行后自动更新RSI和RDI指针。  

`scasb` (Scan String Byte)  

作用：将AL寄存器的值与目标地址(RDI)的字节进行比较。  
常用于在字符串中查找特定字符。  
执行后自动更新RDI指针。  



## 重复前缀指令  

`rep` (Repeat)  

作用：重复执行字符串指令直到RCX=0。  
RCX作为计数器，每次执行后自动递减。  
常与movsb配合实现内存块复制。  

`repe/repz` (Repeat while Equal/Zero)  

作用：重复执行直到RCX=0或ZF=0(不相等)
常与cmpsb配合比较字符串。  
找到第一个不同字符时停止。  

`repne/repnz` (Repeat while Not Equal/Not Zero)  

作用：重复执行直到RCX=0或ZF=1(相等)。  
常与scasb配合在字符。  


```asm
; 示例：
; 复制字符串
mov rsi, source_string
mov rdi, dest_string
mov rcx, string_length
rep movsb                ; 复制rcx个字节

; 比较字符串
mov rsi, string1
mov rdi, string2
mov rcx, string_length
repe cmpsb              ; 比较直到不相等或结束

; 查找字符
mov rdi, string_start
mov rcx, string_length
mov al, 'A'             ; 要查找的字符
repne scasb             ; 查找字符'A'
```
