# Stub和Mock  

Stub：为了“提供可控输入”，让代码能跑/好测
•	目标：隔离外部依赖，给被测代码喂固定数据或简单逻辑。
•	关注点：返回什么（状态）。
•	一般不验证“是否被调用/调用次数/参数”。
例子（概念）：
•	IClock.Now() 返回固定时间
•	IUserRepo.Get(id) 返回固定用户或 null
Mock：为了“验证交互”，确认代码按预期调用了依赖
•	目标：断言行为是否发生。
•	关注点：怎么调用的（行为）：是否调用、调用次数、参数、调用顺序等。
•	常用于验证副作用：日志、消息发送、保存、发布事件等。
例子（概念）：
•	是否调用了 repo.Save(user) 一次
•	是否用正确参数调用了 publisher.Publish(evt)
