# SIMD    

SIMD是单指令多数据的缩写 ，SIMD可以调高程序的性能，是并行计算的一种形式。    

> SIMD的第一个实现是MMX，后来被*数据流SIMD扩展(SSE)*指令集取代，后来的SSE由*Advanced Vector Extension(AVX)*进行了扩展。    

## 标量数据和打包数据    

支持SSE功能的处理器有16个额外的128位寄存器(xmm0-xmm15)和一个控制寄存器mxcsr。    

可以在xmm中存储多个值，称为打包数据。xmm0寄存器可以存储4个32位浮点数、两个64位双精度浮点数。    

AVX寄存器的大小是xmm的两倍，称为ymm寄存器，还有512位的AVX寄存器，称为zmm寄存器。    


## 数据对齐和不对齐    

内存上的数据可以对齐也可以不对齐，对齐可以大大提高程序的性能。    

原因是对齐的SSE指令希望同时获取16字节的内存块，当内存中的数据没有对齐时，CPU必须执行多个获取操作来得到所需的16字节数据，降低执行速度。    

在NASM中，可以在要对齐的数据前使用汇编指令`align 16`和`alignb 16`。

# mxcsr控制和状态寄存器    

|位(bit)|助记符|意义|
|-|-|-|
|0|IE|无效的操作错误|
|1|DE|非规格化(denormal)错误|
|2|ZE|被零除错误|
|3|OE|溢出错误|
|4|UE|下溢错误|
|5|PE|精度错误|
|6|DAZ|非规格化浮点数置零|
|7|IM|无效的操作掩码|
|8|DM|非规格化操作掩码|
|9|ZM|被零除掩码|
|10|OM|溢出掩码|
|11|UM|下溢掩码|
|12|PM|精度掩码|
|13|RC|舍入控制|
|14|RC|舍入控制|
|15|FZ|下溢则零|


## stmxcsr指令和ldmxcsr指令  

stmxcsr(Store MXCSR)将MXCSR寄存器内容存储到内存。    

```asm
stmxcsr [memory]
```

ldmxcsr(Load MXCSR)从内存加载MXCSR寄存器内容。    

```asm
ldmxcsr [memory]
```
