# 窥孔优化    

> 虽然大部分编译器产品通过仔细的指令选择和寄存器分配来生成优质代码，但还有一些编译器使用另一种策略，它们先生成原始的代码，然后对目标代码进行“优化”转换，提高目标代码的指令。    

一个简单有效的、用于局部改进目标代码的技术是*窥孔优化(peephole optimization)*。它在优化的时候检查目标指令的一个滑动窗口(窥孔)，并且只要有可能就在窥孔内使用更快或更短的指令来替换窗口中的指令序列。    

> 窥孔优化并不要求窥孔中的代码连续。    
> 每一次窥孔优化又可能产生新的优化机会，一般会多次扫描目标代码。    


## 消除冗余的加载和保存指令    

```
示例：  
LD R0, a
ST a, R0
```

可以删除其中的保存指令，它冗余的。（除非保存指令前面有一个标号属于另一个基本块）    

## 消除不可达代码    

```
示例：  
    if debug == 1 goto L1
    goto L2
L1: print info
L2:
消除级联跳转指令：  
    if debug != 1 goto L2
    print info
L2:
```

## 控制流优化    

```
示例：  
    goto L1
    ...
L1: goto L2
优化为：  
    goto L2
    ...
L1: goto L2
```

```
示例：  
    if a < b goto L1
    ...
L1: goto L2
优化为：
    if a < b goto L2
    ...
L1: goto L2
```

## 代数化简和强度消减、以及使用机器特有指令    

用于简化DAG的代数恒等式，也可以用于窥孔优化器：  
```
x = x + 0
x = x * 1
以上都可以优化掉
```
强度消减也可以应用到窥孔优化，把代价较高的计算替换为目标机器上代价较低的计算：    
```
x^2  -->  x * x
x*2  -->  x << 1
x = x + 1  -->  x++
```
