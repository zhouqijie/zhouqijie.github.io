# 绘制编辑器元素  

## 文本    

`GUILayout.Label();`  
`EditorGUILayout.Label();`    
`GUILayout.Label("xxxx", EditorStyles.label);`    

## 按钮  

```C#
if(GUILayout.Button("Btn"))
{
    Debug.Log("Clicked");
}
```

## 开关  

```C#
this.isOn = GUILayout.Toggle(this.isOn, "Toggle1");
```

## 输入框    

```C#  
this.txt = EditorGUILayout.TextField("Text", this.txt);
this.fvalue = EditorGUILayout.FloatField("FValue", this.fvalue);
this.fvalue = EditorGUILayout.FloatField("FValue", this.fvalue);
//...
```


## 下拉列表    

```C#  
this.enumval = (MyEnum)EditorGUILayout.EnumPop("EnumValue", this.enumval);
```

## 滑动条    

```C#
this.intval = EditorGUILayout.IntSlider("IntValue", this.intval, 0, 5);
```

## 折叠栏    

```C#  
this.isFolding = EditorGUILayout.Foldout(this.isFolding, "折叠", true);
if(this.isFolding)
{
    GUILayout.Label("...");
    GUILayout.Label("...");
}
```

# 编辑器布局    

## 水平/垂直布局    

`GUILayout.BeginHorizontal();`    
`GUILayout.EndHorizontal();`    
`GUILayout.BeginVertical();`    
`GUILayout.EndVertical();`    

## ScrollView    

```C#  
pos = GUILayout.BeginSrollView(pos);
//......
GUILayout.EndScrollView();
```

## 元素的尺寸设置    

示例：    
```C#
GUILayout.Button("Btn1", GUILayout.Width(100f), GUILayout.Height(50f));
```  

类型：      
`MaxWidth`、`MinWidth`、`ExpandWidth`      


## 间隙    

```C#
//BeginLayout
GUILayout.XXX("XXX", GUILayout.Width(50f));
//   GUILayout.Space(100f);
//or GUILayout.FlexibleSpace();
GUILayout.XXX("XXX", GUILayout.Width(50f));
//EndLayout  
```
