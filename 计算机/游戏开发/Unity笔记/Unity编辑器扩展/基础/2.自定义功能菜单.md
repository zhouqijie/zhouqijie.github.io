# 自定义功能菜单    

## MenuItem    

`MenuItemAttribute`可以创建新的功能菜单项。（顶部菜单栏和Hierarchy右键菜单）  

> 当路径以`GameObject/`开始时，会被添加到Hierarchy窗口的右键菜单中。    

> 当路径以`Assets/`开始时，会被添加到Project窗口的右键菜单中。    

> 当路径以`CONTEXT/<组件名>/`开始时，会被添加到组件下拉菜单中。（和ContextMenuAttribute一样）    

#### 参数itemName：      

除了设置菜单栏路径，还能指定快捷键。    

|快捷键|字符串|
|-|-|
|`ctrl`|`%`|
|`shift`|`#`|
|`alt`|`&`|
|方向键|`LEFT/RIGHT/UP/DOWN`|
|功能键|`F1/.../F12`|


示例：  
```C#  
[MenuItem("自定义/Test %A")]
public static void Test()
{
    //...
}
```   

#### 参数priority    

靠前显示的优先级。    

#### 参数isValidateFunction    

参数`isValidateFunction`为`true`指定一个函数为Validate函数。    

```C#  
[MenuItem("AAA/BBB")]
private static void BBB(){}
[MenuItem("AAA/BBB", true)]
private static bool BBB_Validate(){ return true; }
```

## ContextMenu(Attribute)      

在组件的下拉列表中创建新的项。和MenuItem类似，有`isValidateFunction`和`priority`两个可选参数。但是`ContextMenuAttribute`是用于实例方法(Non-Static)的。  

<br />
<br />

## ContextMenuItem(Attribute)    

用于组件的某个Field。右键该Field会弹出该项。    

```C#
public class Player: MonoBehaviour
{
    [ContextMenuItem("升级", "OnLevelUp")]
    public int lvl;

    public void OnLevelUp(){ this.lvl += 1; }
}
```
