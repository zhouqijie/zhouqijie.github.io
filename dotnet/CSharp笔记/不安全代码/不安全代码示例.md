# C#不安全代码示例      


### 在栈上分配连续空间    

`byte* stackPtr = stackalloc byte[1024];`
`Span<byte> stackPtr = stackalloc byte[1024];`

> `Span<T>`可以看作一个安全的、带边界检查的数组指针，它是一个引用类型。    


### 结构体中定义连续空间    

```C#
public struct MyStruct
{
    public int id;
    public fixed byte buffer[1024];
}
Console.WriteLine(sizeof(MyStruct)); //输出结果：1028  
```

> `fixed`关键字有两种用法，一种是结构体内定义连续数组（或者说内联数组），一种用于固定托管堆上的对象。    

### 在堆上面分配结构体    

方法一：使用引用类型（数组或者容器）来固定
```C#  
class Container {public MyStruct data;}
Container container = new Container();
fixed(MyStruct * ptr = &container.data)
{
    //访问堆上的结构体  
}
```

方法二：使用Marshal  
```C#
MyStruct data = new MyStruct();
IntPtr ptr = Marshal.AllocHGlobal(Marshal.SizeOf<MyStruct>()); // 分配非托管内存
Marshal.StructureToPtr(data, ptr, false); // 复制结构体到非托管内存
MyStruct* sPtr = (MyStruct*)ptr.ToPointer(); // 转换为指针
// 访问堆上的结构体  
Marshal.FreeHGlobal(ptr); // 必须手动释放内存
```  

方法三：使用GCHandle    
```C#  
MyStruct[] arr = { new MyStruct() };
GCHandle handle = GCHandle.Alloc(arr, GCHandleType.Pinned); // 固定数组
IntPtr ptr = handle.AddrOfPinnedObject(); // 获取首元素地址
MyStruct* sPtr = (MyStruct*)ptr.ToPointer();
// 访问堆上的结构体  
handle.Free(); // 释放句柄
```  

方法四：NativeMemory（Mono没有）    
```C#  
// 分配内存（自动零初始化）
Point3D* ptr = (Point3D*)NativeMemory.Alloc(
    elementCount: 1,      // 分配 1 个结构体
    elementSize: sizeof(Point3D)
);
// 直接通过指针操作结构体
ptr->X = 10.0f;
ptr->Y = 20.0f;
ptr->Z = 30.0f;
// 使用后释放内存
NativeMemory.Free(ptr);
```

### 从字节数组读取结构体    

```C#  
unsafe T ReadStructFromBuffer(byte[] buffer)
{
    fixed(byte* ptr = buffer)
    {
        return *(MyStruct*)ptr;
    }
}
```  


### 结构体布局    

多视角数据访问（类似C++的union）：    
```C#  
[StructLayout(LayoutKind.Explicit)]
unsafe struct MemoryView
{
    [FieldOffset(0)] public fixed byte Bytes[8];
    [FieldOffset(0)] public long LongValue;
    [FieldOffset(0)] public double DoubleValue;
}
```
