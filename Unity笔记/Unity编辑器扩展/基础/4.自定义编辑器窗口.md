# 自定义编辑器窗口    

### 示例    

```C#

public class WindowTest : EditorWindow
{
    public static WindowTest window;

    [MenuItem("自定义/窗口/WindowTest")]
    public static void OpenWindow()
    {
        window = EditorWindow.GetWindow<WindowTest>(false, "WindowTest", true); //Instantiate
        window.Show(); //Show
    }

    public void OnGUI()
    {
        //...
    }
}
```  

### EditorWindow的回调    

|方法|描述|
|OnEnable|窗口打开|
|OnGUI|绘制GUI|
|OnValidate|脚本加载|
|OnDisable|窗口关闭|
|OnDestroy|OnDisable之后|

### Wizard窗口    

示例：  
```C#
public class TestWizard : ScriptableWizard
{
    public int number;
    public string str;

    void OnWizardUpdate()
    {
        string helpString = "Log string number times";
        bool isValid = (number > 0) && (str != null);
    }

    void OnWizardCreate()
    {
        for(int i = 0; i < number; i++)
        {
            Debug.Log(str + " (" + i + ")");
        }
    }

    [MenuItem("自定义/Wizards/Test")]
    static void Test()
    {
        ScriptableWizard.DisplayWizard<TestWizard>(
            "Test Wizard", "Test!");
    }
}
```

```C#  
public class CustomHierarchyWindow
{
    [InitializeOnLoadMethod]

    {
        EditorApplication.hierarchyWindowItemOnGUI -= OnItemGUI;
        EditorApplication.hierarchyWindowItemOnGUI += OnItemGUI;
    }

    private static void OnItemGUI(int instanceID, Rect selectionRect)
    {
        GameObject go = EditorUtility.InstanceIDToObject(instanceID) as GameObject;
        if(go == null) return;

        foreach(var com in go.GetComponents<Component>())
        {
            //GUI.Label();.....
        }
    }
}
```

### 扩展Project窗口    

```C#  
//前面部分和扩展Hierarchy窗口类似    
private static void OnProjectItemGUI(string guid, Rect selectionRect)
{
    string assetPath = AssetDatabase.GUIDToAssetPath(guid);
    string[] dependencies = AssetDatabase.GetDependencies(assetPath);
    
    Rect rect = selectionRect;
    rect.x += selectionRect.width - 20f;
    rect.width = 20f;
    GUI.Label(rect, dependencies.Length.ToString());
}
```
