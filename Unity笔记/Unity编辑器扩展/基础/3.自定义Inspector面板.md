# 定义Editor类    

自定义组件的检视面板，首先需要先定义该组件的Editor类。    

```C#
[CustomEditor(typeof(PlayerCom))]
pubic class PlayerComEditor : Editor
{}
```  

|事件函数||
|-|-|
|`Awake()`|组件的GO被选中时触发|
|`OnEnable()`|组件的GO被选中时触发，在Awake之后|  
|`OnValidate()`|检视面板的值被修改时触发|
|`OnDisable()`|取消选中时触发|  
|`OnDestroy()`|取消选中时触发，在OnDisable之后|  


## 自定义Inspector面板的GUI    

Editor基类的`OnInspectorGUI`虚函数定义了组件的Inspector如何绘制。可以重载`OnInspectorGUI`虚函数来自定义绘制GUI。    

如果需要扩展原来的GUI，可以调用基类方法`base.OnInspectorGUI()`，如果需要完全自定义就不需要调用基类方法。    

可以通过反射方式修改字段值，但是更常见的是使用SerializedProperty。    

```C#
private void OnEnable()
{
    player = target as Player;
    this.lvlProperty = serializedObject.FindProperty("lvl");
    //...
}
private override void OnInspectorGUI()
{
    lvlProperty.intValue = EditorGUILayout.IntField("Player Level", lvlProperty.intValue);
}

```

## 检测和应用修改    

几种检测修改的方法：    
1. 直接对比控件修改后的值与现有的字段值。    
2. `GUI.changed`属性。    
3. `EditorGUI.BeginChangeCheck()/EndChangeCheck()`方法。    

应用修改：    
```C#  
if(GUI.changed)
{
    //（应用属性修改后，还需标记为Dirty，然后才能使用ctrl+s完成保存）    
    serializedObject.ApplyModifiedProperties();
    EditorUtility.SetDirty(tgt);
}
```

## 撤销和重做    

#### `Undo.RecordObject()`    

记录Object的状态。在给对象的某个序列化属性赋值之前调用，之后就可以ctrl+z撤销修改。    

```C#  
Undo.RecordObject(tgt, "Changed");
tgt.xxx = "new value";
serializedObject.ApplyModifiedProperties();
EditorUtility.SetDirty(tgt);
```  

#### `Undo.AddComponent()`    

Undo类的AddComponent添加的组件，支持撤销和恢复。    

#### `Undo.RegisterCreatedObjectUndo()`    

创建对象之后，调用该方法来注册撤销操作。    

#### `Undo.DestroyObjectImmediate()`    

如果要在编辑器Destroy一个对象，可以使用该方法，让Destroy的对象保存在撤销缓冲区。    

#### `Undo.SetTranformParent()`    

修改Tranform的父对象时，可以调用该方法来支持撤销操作。

## 自定义预览(Preview)窗口

```C#
//是否开启预览窗口  
public override bool HasPreviewGUI()

    GUILayout.Button("Btn2" EditorStyle.toolbarButton);
}
//绘制窗口GUI  
public override void OnPreviewGUI(Rect rect, GUIStyle bg)
{
    //...
}

```

#### PreviewRenderUtility    

`PreviewRenderUtility`是用于预览渲染的Utils类，它可以在预览窗口中提供一个预览场景，可在该场景添加物体以及调整灯光相机等渲染参数。    

|函数|描述|
|-|-|
|`BeginPreview()`|开始预览|
|`EndPreview()`|结束预览|
|`BeginStaticPreview()`|开始Static预览|
|`EndStaticPreview()`|结束Static预览|
|`AddSingleGO()`|添加GO|
|`Cleanup()`|清理场景|


```C#
        private InspectorTest_Player tgt;
        
        //预览相关  
        private PreviewRenderUtility previewRdrUtil;
        private GameObject goPreview;
        private bool isPlaying;

        private void Awake()
        {
        }
        private void OnEnable()
        {
            tgt = (target as InspectorTest_Player);
            //预览相关  
            goPreview = Instantiate(tgt.gameObject, Vector3.zero, Quaternion.identity);
            previewRdrUtil = new PreviewRenderUtility(true );
            previewRdrUtil.AddSingleGO(goPreview);
            EditorApplication.update += Update;
        }
        private void Update()
        {
            if(isPlaying)
            {
                goPreview.transform.Rotate(Vector3.one * 90f * Time.deltaTime);
                Repaint();
            }
        }
        private void HandleInput()
        {
            int controlID = GUIUtility.GetControlID(GetType().GetHashCode(), FocusType.Passive);
            switch(Event.current.GetTypeForControl(controlID))
            {
                case EventType.MouseDown:
                    break;
                case EventType.MouseUp:
                    break;
                case EventType.MouseDrag:
                    break;
                case EventType.ScrollWheel:
                    break;
            }
        }

        public override void OnInspectorGUI ()
        {
        }

        public override bool HasPreviewGUI()
        {
            return true;
        }
        public override GUIContent GetPreviewTitle()
        {
            return new GUIContent("TestTitle");
        }
        public override void OnPreviewSettings()
        {
            if(!isPlaying)
            {
                if (GUILayout.Button("开始预览"))
                {
                    isPlaying = true;
                }
            }
            else
            {
                if(GUILayout.Button("结束预览"))
                {
                    isPlaying = false;
                }
            }
        }
        public override void OnPreviewGUI(Rect r, GUIStyle background)
        {
            if(Event.current.type == EventType.Repaint)
            {
                GUI.Label(new Rect(r.position, new Vector2(200, 30f)), new GUIContent($"isPlaying:{isPlaying}"));

                previewRdrUtil.BeginPreview(r, background);
                {
                    Camera camera = previewRdrUtil.camera;
                    camera.transform.rotation = Quaternion.LookRotation(Vector3.forward);
                    camera.transform.position = new Vector3(0f, 0f, -10f);
                    camera.Render();
                }
                previewRdrUtil.EndAndDrawPreview(r);
            }
        }

        private void OnDisable()
        {
            EditorApplication.update -= Update;
            previewRdrUtil.Cleanup();
            previewRdrUtil = null;
            DestroyImmediate(goPreview);
        }
```

## 扩展内置组件的编辑器面板    

内置组件的Editor类不是可见的，只能通过反编译获取。    

可调用`Editor.CreateEditor()`创建编辑器。    

```C#
private Editor editorInstance;
private MethodInfo onSceneGUI;

private void OnEnable()
{
    var editorType = Assembly.GetAssembly(typeof(Editor)).GetTypes().FirstOrDefault(m => m.Name == "RectTransformEditor");
    editorInstance = CreateEditor(targets, editorType);
    onSceneGUI = editorType.GetMethod("OnSceneGUI", BindingFlags.Instance | BindingFlags.Static | BindingFlags.Public | BindingFlags.NonPublic);
}
private void OnSceneGUI()
{
    if(editorInstance)
        onSceneGUI.Invoke(editorInstance);
}
public override void OnInspectorGUI()
{
    editorInstance.OnInspectorGUI();
    
    //扩展的内容
    //...
}
private void OnDisable()
{
    if(editorInstance != null)
    DestroyImmediate(editorInstance);
}
```

### 自定义PropertyDrawer    

```C#
public class Foo
{
    public int field1;
    public float field2;
}    

[CustomPropertyDrawer(typeof(Foo))]
public sealed class FooPropertyDrawer : PropertyDrawer
{       
    public override float GetPropertyHeight(SerializedProperty property, GUIContent label)
    {
        return 100f;
    }
    public override void OnGUI(Rect position, SerialzedProperty property, GUIContent lable)
    {
        EditorGUI.BeginProperty(position, GUIUtility.GetControlID(FocusType.Passive), label);
        
        SerialzedProperty prop_field1 = property.FindPropertyRelative("field1");
        SerialzedProperty prop_field2 = property.FindPropertyRelative("field2");

        float currY = position.y;
        propName.stringValue = EditorGUI.TextField(new Rect(position.x, currY, position.width, 25f), propName.stringValue); 
        currY += 25f;
        propDamage.intValue = EditorGUI.IntField(new Rect(position.x, currY, position.width, 25f), propDamage.intValue); 
        currY += 25f;
        //...

        EditorGUI.EndProperty();
    }
}
```
